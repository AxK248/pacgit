## Installing pacgit:

### Windows
```pacwin | cmd
curl -sL "https://raw.githubusercontent.com/axk248/pacgit/main/pacgit.bat" -o "%temp%\temp.bat" && call "%temp%\temp.bat" && del "%temp%\temp.bat"
```
